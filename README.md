# TripPilot AI

TripPilot AI is an AI-powered full-stack travel planning web application that helps users generate personalized travel itineraries, manage travel expenses, view real-time weather updates, explore destinations on interactive maps, and share travel plans with the community.

## Features

- AI-powered travel itinerary generation
- Interactive maps with Leaflet
- Real-time weather updates
- Expense tracker with data visualization
- AI-powered travel journal with image analysis
- JWT-based user authentication
- Community itinerary sharing and cloning
- Responsive user interface

## Tech Stack

**Frontend:** React.js, Bootstrap 5, Leaflet.js, Recharts

**Backend:** Django, Django REST Framework

**Database:** PostgreSQL / SQLite / MySQL

**APIs:** Gemini API, OpenWeather API

**Tools:** Git, GitHub, Postman
